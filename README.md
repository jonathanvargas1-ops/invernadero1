invernadero

Sistema web para la gestión de invernaderos domésticos. Permite a cada usuario administrar su propio invernadero, cultivos y sensores, mientras que un administrador supervisa las cuentas de usuario y las estadísticas globales del sistema.

rutas disponibles

- `/login.html` → Inicio de sesión
- `/invernadero.html` → Vista principal del invernadero del usuario
- `/cultivos.html` → Gestión de cultivos del usuario
- `/sensores.html` → Gestión de sensores del usuario
- `/admin_usuarios.html` → Panel de administración de usuarios
- `/admin_estadistica.html` → Estadísticas globales del sistema
